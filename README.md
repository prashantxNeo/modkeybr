# modkeybr

A modified version of Keybr.

Forked from [keybr.com](https://github.com/aradzie/keybr.com)


(https://github.com/aradzie/keybr.com)

## Why?

Let's say your overall typing speed is 70+ WPM, but for letter `Q` it's only 45 WPM. `Q` is rarely used so spending too much time practicing may not be worthwhile.

However, keys like `C`, `B`, `V`, and `X` might also be 50–55 WPM while being used more frequently. If your target is 60 WPM, Keybr may keep generating lessons for `Q` instead of  important keys.

To solve this, `modkeybr` allows you to **pause specific low-priority keys** such as `Q` and `Z`. Temporarily ignoring rarely used outlier keys and focus on improving important ones.


## Changes

* Paused keys

  * Pause individual keys.
  * Pause multiple keys at same time to target specific keys.
  * Paused keys do not block progression.
  * Key statistics are preserved.
  * Unpause anytime.

## Goal

* Avoid getting stuck on outlier keys.
* Keep normal Keybr progression.
* Practice more efficiently.
